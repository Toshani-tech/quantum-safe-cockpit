# quantum-safe-cockpit

Overview: 

This project presents a high fidelity simulation of an industrial avionics flight deck, designed to model telemetry performance within electronically contested environments. By integrating NIST standardized ML KEM (lattice based) cryptography, the platform serves as a testbed for hardening aerospace communication against emerging quantum computational threats. Through a focus on deterministic execution and rigorous data serialization, this work addresses the critical imperative for high-integrity, secure messaging protocols in next generation aviation systems.
